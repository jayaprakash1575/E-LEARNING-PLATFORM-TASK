# JP Academy — India's Premier Tech & AI Academy

A high-performance modern e-learning platform built with React 19, Tailwind CSS v4, and Vite, featuring immersive widescreen layouts, authentic South Indian engineering masterclasses, interactive quiz modules, live note-taking, and verifiable credentials.

## 🚀 Key Features

- **Panoramic & Widescreen Responsive Design**: Zero empty side margins with high-tech HUD cockpit telemetry, live community pulse, and edge-to-edge blueprints.
- **Production Masterclasses**: Courses designed around high-concurrency systems (Zoho, Freshworks, Swiggy, Flipkart, CRED, Razorpay).
- **Interactive Classroom**: Custom video player with 0.75x–2.0x playback, keyboard shortcuts, persistent timestamped notebook, and instant-graded quizzes.
- **Verifiable Credentials**: Official AICTE & ISO 9001:2015 aligned certificates with unique IDs and QR verification.
- **South Indian Faculty & Hubs**: Real-world curriculum led by instructors from Bengaluru, Chennai, Hyderabad, and IIT Madras Research Park.

## 🛠️ Tech Stack

- **Frontend**: React 19, React Router v7
- **Styling**: Tailwind CSS v4 (`@tailwindcss/vite`), Vanilla CSS tokens
- **Icons**: Lucide React
- **Animations**: Canvas Confetti, Tailwind CSS keyframes
- **Build Tool**: Vite 8 with HMR

## 📦 Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build production bundle
npm run build

# Run linter
npm run lint
```
